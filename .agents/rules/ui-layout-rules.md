# [필수 UI 디자인 및 레이아웃 규칙] 메뉴·버튼·테이블 한 줄(단일 행) 표시 원칙

이 문서는 본 프로젝트(`imsil`)에서 UI/UX를 개발하거나 수정할 때 **반드시 준수해야 하는 핵심 디자인 규칙**입니다.

---

## 1. 메뉴 및 버튼의 한 줄 표시 원칙 (No-Wrap)
- **줄바꿈 절대 방지**: 상단 메뉴, 탭, 필터 툴바, 액션 버튼 그룹 등 모든 메뉴와 버튼은 글자나 버튼이 세로로 쪼개지거나 어설프게 다음 줄로 밀리지 않도록 **한 줄(단일 행)로 유지**해야 합니다.
- **클래스 가이드**:
  - 부모 컨테이너: `flex-nowrap`, `items-center` 기본 적용.
  - 버튼/아이템: `whitespace-nowrap`, `shrink-0` 적용.
  - 가로 폭이 좁은 모바일/소형 화면의 경우, 줄바꿈으로 깨뜨리지 말고 **가로 스크롤(`overflow-x-auto no-scrollbar` 또는 `overflow-x-auto`)**을 적용하여 가로 형태로 온전히 유지합니다.

---

## 2. 테이블 데이터 셀 및 뱃지의 글자 쪼개짐 방지 (No-Wrap)
- **셀 내용 세로 쪼개짐 금지**:
  - `수량` (예: `1박\n스`, `14\n박스` 등 단어가 줄바꿈되어 세로로 나뉘는 현상 방지)
  - `입금 상태 뱃지` (예: `미\n입\n금` 등 3줄로 쪼개지는 현상 방지)
  - `주문/배송 상태 뱃지` (예: `포\n장\n대\n기` 등 4줄로 쪼개지는 현상 방지)
  - `도착일 / 연락처 / 금액` 등 핵심 정보 컬럼
- **규칙**:
  - 모든 `<th>`, `<td>` 및 뱃지(`<span>`)에 `whitespace-nowrap`을 필수로 적용합니다.
  - 뱃지 컨테이너에 `inline-block` 또는 `inline-flex`, `shrink-0`, `min-w-fit`을 적용합니다.
  - 테이블 전체는 `overflow-x-auto`로 감싸 화면이 좁아지더라도 테이블 셀 내부 글자가 줄바꿈되어 깨지는 대신 테이블 전체가 부드럽게 가로 스크롤되도록 구성합니다.
  - 주소나 메모 등 가변적인 긴 텍스트 열은 `truncate`와 적절한 `min-w-[...]` 및 `max-w-[...]`를 설정하여 다른 정형 데이터 열의 폭을 침범하거나 찌그러뜨리지 않도록 합니다.

---

## 3. 체크리스트
새로운 컴포넌트를 만들거나 수정할 때 다음 항목을 반드시 확인합니다:
- [ ] 버튼이나 메뉴 라벨에 `whitespace-nowrap`이 적용되어 있는가?
- [ ] 버튼 그룹에 `flex-nowrap shrink-0`이 적용되어 있는가?
- [ ] 테이블의 상태 뱃지나 수량, 금액 셀에 `whitespace-nowrap`이 적용되어 글자가 세로로 깨지지 않는가?
- [ ] 화면 폭이 좁아졌을 때 줄바꿈으로 UI가 깨지는 대신 부드러운 가로 스크롤(`overflow-x-auto`)이 작동하는가?
